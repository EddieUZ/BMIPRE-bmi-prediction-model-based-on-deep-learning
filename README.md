# 基于人脸图像的BMI预测算法项目

## 项目介绍

本项目基于人脸图像，通过深度学习技术进行BMI（身体质量指数）的预测。参考了邹睿智等人的研究（《基于人脸图像的BMI预测算法研究》，计算机应用与软件，2019），我使用当下流行的深度学习技术，采用卷积神经网络（CNN）模型，成功实现了对人脸图像的BMI初步预测。通过对比传统的特征提取方法（如面部区域面积比、嘴颌宽度比、颊宽高度比），本项目利用神经网络自学习的黑箱操作进行BMI的预测，具有较高的准确性和更强的通用性。

## 项目创新点

1. **数据集扩展** ：本项目使用了一个相较传统方法扩展了百余人的人脸数据集，进一步提高了模型的泛化能力。
2. **深度学习技术的应用** ：不同于传统的面部特征提取方法，项目使用了CNN深度学习模型，摆脱了手工特征选择的限制，让模型通过自学习完成BMI的预测任务。
3. **神经网络黑箱操作** ：通过CNN的多层网络结构，模型能够从人脸图像中提取深层特征，进而完成BMI的预测任务，不依赖传统的人工提取特征。

2. **模型选择** ：
   * 如果直接使用训练好的模型，可以直接下载`.pth`文件以及`testcode.py`文件。
   * 若想自行训练模型，则需要下载完整的人脸数据集（face集）并进行训练。

## 项目中的困难点

1. **模型调优** ：模型建立的过程中，每次调整学习率、训练轮次、数据尺寸等超参数都会对模型的拟合效果产生重大影响。这些参数的调节是一个反复试错的过程，且每一次调整都需要耗费大量的心智。
2. **平台差异** ：不同的训练平台和预处理模型的选择会影响模型的效果，部署过程中可能面临不同平台间的兼容性问题，此外还涉及到网络和支付等外部因素的挑战。
3. **数据处理** ：从数据的预处理到最终的模型训练，数据的质量和处理方式对最终效果至关重要，尤其是在数据集较大时，处理效率也是一大挑战。
